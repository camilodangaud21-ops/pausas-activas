# Índice de habilidades

Este repositorio no contiene skills reutilizables empaquetadas. Sus flujos de trabajo locales son:

| Habilidad                   | Referencia                                       | Uso                                                                  |
| --------------------------- | ------------------------------------------------ | -------------------------------------------------------------------- |
| Consultar y ampliar la wiki | [`wiki/instrucciones.md`](wiki/instrucciones.md) | Leer el índice y registrar conceptos mediante MCP                    |
| Añadir ejercicios           | [`README.md`](README.md)                         | Crear una implementación `BaseExercise` y registrarla en el detector |
| Probar la lógica            | [`AGENTS.md`](AGENTS.md)                         | Ejecutar `python -m pytest test/` sin cámara ni UI                   |

Los enlaces externos de OKF están documentados en `AGENTS.md` y en la nota local del proyecto; no se afirma que exista una copia local del OKF.
